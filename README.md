### Featured build · Nexora AI

> **An agentic assistant that can calculate, search the web, and retrieve information from PDFs.**

<table>
<tr>
<td width="50%" valign="top">

**Agent workflow**

Native LLM function calling routes requests to a calculator, web search, or document knowledge base. A multi-step loop returns tool observations to the model.

</td>
<td width="50%" valign="top">

**Hybrid document retrieval**

Sentence Transformer embeddings and BM25 combine semantic and keyword search. Reciprocal Rank Fusion merges results stored in ChromaDB.

</td>
</tr>
</table>

**Python · Streamlit · Groq / Qwen · ChromaDB · Sentence Transformers · BM25 · PyPDF**

[**View code & setup →**](https://github.com/Anilyadav1718/Agentic-AI-with-RAG)

<details>
<summary><b>Explore the architecture and example interactions</b></summary>

<br>

**Request → agent → tool selection → tool result → response**

- **Calculate:** “Calculate 9382 × 72” routes to the calculator.
- **Search:** A request for current information can use web search.
- **Ask a document:** A question about an uploaded PDF uses hybrid retrieval to supply context.
- **Inspect sources:** The interface exposes retrieved pages and ranking information.

This is an engineering/demo project. Current constraints include local document storage, session-based conversation memory, and API rate limits.

</details>
